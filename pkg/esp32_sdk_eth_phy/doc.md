@defgroup pkg_esp32_sdk_eth_phy ESP32x SDK Ethernet PHY drivers
@ingroup  pkg
@brief    Ethernet PHY drivers for the ESP32 EMAC

Since ESP-IDF v6.0, the drivers for the Ethernet PHYs DP83848, IP101,
KSZ80xx, LAN87xx and RTL8201 are no longer part of ESP-IDF but are maintained
in the [ESP-IDF Ethernet Drivers](https://github.com/espressif/esp-eth-drivers)
repository. This package provides these drivers for the ESP32 Ethernet MAC
(module `esp_eth`).
