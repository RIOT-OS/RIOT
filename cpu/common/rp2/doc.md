@defgroup    cpu_common_rp2 RP2 Common
@ingroup     cpu_common
@brief       Code shared by the RP2040 and the RP2350

The RP2040 and the RP2350 share some peripherals.
Drivers for these peripherals are located in `cpu/common/rp2`, which is used by
both @ref cpu_rpx0xx and @ref cpu_rp2350. The name follows the `rp2_common`
folder of the Pico SDK.
