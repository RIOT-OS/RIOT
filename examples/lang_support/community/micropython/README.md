## Overview

This application provides an example on how to use MicroPython with RIOT.
Please see the documentation of pkg/micropython.

WARNING: RIOT's MicroPython port is currently quite incomplete!

## MicroPython remote control
Another way to use this example, is by using the MicroPython remote control
tool `mpremote`. This tool provides a convenient way to interact with the
MicroPython REPL over a serial connection. Refer to the [documentation][1] for
more information on how to install and use it.

[1]: https://docs.micropython.org/en/latest/reference/mpremote.html
